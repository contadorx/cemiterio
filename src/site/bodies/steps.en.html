Steps Recorder is gone. What do you use instead?

Updated 14 August 2026.
A short guide for anyone who opened psr.exe, found the deprecation notice, and still has to hand in the document it used to produce.

What happened

Since the February 2024 Windows 11 update, Steps Recorder (psr.exe) shows a deprecation notice when it opens. It still runs on many machines, but it gets no further development and is not on Microsoft's roadmap.

The alternatives Microsoft itself points to are the Snipping Tool, the Xbox Game Bar and Clipchamp. And here is the problem: none of the three produces a step document. They make images and video. What disappeared is exactly the part that mattered — automatically assembling a numbered document with one screen per step.

Who was left without a tool

  • Manual testing and UAT, which has to prove the test happened, screen by screen.
  • Support and service desks, which ask users to “reproduce it and send me the steps”.
  • Internal audit and ITGC, which receive that evidence.
  • Training and process documentation, which assemble the walkthrough in Word.

All with the same mandatory task as before, and without the program that solved it.

What {{marca}} does instead

{{marca}} records the screen and assembles the document: one step per block, numbered, with the image, the time and the description. It exports PDF, Word, a ZIP of images or JSON. It runs in the browser, with nothing to install, and the video never leaves your computer.

Where Steps Recorder was better

Worth saying, because the difference changes the result: psr.exe talked to the operating system and knew which control you had clicked — the button name, the field, the window. A browser has no such access, and no web tool does.

{{marca}} makes the opposite trade: it keeps a frame every time the screen changes, and the description comes from you, speaking while you work. Less automatic, more explanatory. In practice, “user clicked on Button” never explained anything to anyone; “here I saved without a cost centre and the system refused it” does.

How to do what you used to do

  1. Open the tool — no install, no sign-up.
  2. In step 3 (Review), pick the output model: Step-by-step guide for documentation and training, Test evidence for UAT and audit.
  3. Click Record the screen. If you want to narrate what you are doing, leave the microphone on — that is what becomes each step's description.
  4. Do what you would normally do. The tool keeps a frame every time the screen changes.
  5. Stop, discard the repeated screens, and click use the speech as the note to fill each step's description with what you said. Correct whatever needs correcting.
  6. Generate the PDF or the Word file. It comes out named after the case, not “screenshot”.

And SAP Solution Manager?

Same story, different date. The SAP Solution Manager Test Suite leaves mainstream maintenance at the end of 2027 (extended maintenance to 2030). Its successor, SAP Cloud ALM, has test management — but the visual evidence is still a screenshot attached by hand.

It is exactly the same hole: the management tool exists, and the expensive part to produce — the right screens, in order, with the time and an explanation of what was being done — went back to Print Screen and Word. The Test evidence model was built for that.

Questions that always come up

Does the video get uploaded anywhere?

No. Everything happens in the browser tab, and you can verify it in thirty seconds by opening the browser's network tab. There is a whole page about that, including the list of certifications we do not hold.

Does it work without internet?

It does: there is a single-file version that runs offline and that your team can keep internally. Without a network you lose automatic transcription and type the notes by hand.

Do I have to install anything?

No. That is the whole argument: on a locked-down workstation, “install this program” is a project with an owner and a deadline; opening a web address is one click.

What if I use SAP GUI for Windows?

Screen capture takes any window the operating system lets you share, SAP GUI included — what a browser cannot do is read the fields inside it, the way an installed tool would. For Fiori, S/4 web, Ariba, SuccessFactors and Concur there is no difference at all.
